# VITARE — Portofolio Kreatif dan Jurnal

## Tentang Proyek

VITARE merupakan tema WordPress yang dirancang untuk membangun website portofolio kreatif dan jurnal pribadi. Tema ini menampilkan proyek, artikel, dan berbagai eksplorasi kreatif melalui tampilan yang modern, minimalis, dan menarik.

Proyek ini dikembangkan sebagai bagian dari pembelajaran Content Management System (CMS) dengan memanfaatkan WordPress dan bahasa pemrograman web.

## Fitur Website

- **Beranda:** Menampilkan pengenalan website dan konten pilihan.
- **Portofolio:** Menampilkan proyek kreatif dan artikel pilihan.
- **Jurnal:** Menampilkan kumpulan artikel yang telah diterbitkan.
- **Detail Artikel:** Menampilkan isi artikel secara lengkap.
- **Arsip:** Mengelompokkan artikel berdasarkan kategori atau arsip.
- **Pencarian:** Membantu pengunjung menemukan konten yang dibutuhkan.
- **Desain Responsif:** Dirancang agar tampilan dapat menyesuaikan berbagai ukuran layar.
- **Identitas Visual:** Menggunakan desain modern dengan perpaduan warna biru pastel, sian, ungu, dan lilac.

## Teknologi yang Digunakan

- WordPress sebagai sistem manajemen konten.
- PHP untuk pengembangan templat dan fungsi tema.
- HTML untuk menyusun struktur halaman.
- CSS untuk mengatur tampilan dan desain website.
- MySQL/MariaDB sebagai sistem basis data WordPress.

## Struktur File Tema

Berikut merupakan beberapa file utama yang terdapat dalam tema VITARE:

- `style.css` — Menyimpan informasi tema dan aturan tampilan website.
- `functions.php` — Mengatur fungsi dan konfigurasi tema.
- `header.php` — Mengatur bagian kepala website dan navigasi.
- `footer.php` — Mengatur bagian bawah website.
- `front-page.php` — Mengatur tampilan halaman beranda.
- `home.php` — Mengatur tampilan daftar artikel atau jurnal.
- `index.php` — Menjadi templat utama cadangan.
- `single.php` — Mengatur tampilan detail artikel.
- `page.php` — Mengatur tampilan halaman statis.
- `archive.php` — Mengatur tampilan halaman arsip.
- `search.php` — Mengatur tampilan hasil pencarian.
- `404.php` — Mengatur tampilan halaman ketika konten tidak ditemukan.
- `sidebar.php` — Menyediakan templat untuk bagian bilah samping.

## Cara Memasang Tema

1. Siapkan instalasi WordPress pada server lokal atau layanan hosting.
2. Salin folder tema `vitare` ke dalam direktori `wp-content/themes/`.
3. Buka halaman administrator WordPress.
4. Pilih menu **Tampilan → Tema**.
5. Aktifkan tema VITARE.
6. Atur halaman beranda, menu navigasi, kategori, dan konten sesuai kebutuhan.

## Dokumentasi Screenshot

Dokumentasi tampilan website tersedia di dalam folder `screenshots/`. Folder ini digunakan untuk menyimpan tangkapan layar halaman beranda, portofolio, jurnal, dan detail artikel.
